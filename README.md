# 🎬 DỰ ÁN TIN HỌC LỚP 12 - HUY VŨ MOVIE

Chào mừng bạn đến với dự án cuối kỳ môn Tin học lớp 12! Đây là một trang web xem phim được thiết kế với giao diện hiện đại, lấy cảm hứng từ Netlfix, nhằm trình bày các kỹ năng lập trình web cơ bản.

## 📝 Thông tin dự án
- **Tên dự án:** Website Xem Phim Huy Vũ
- **Mục tiêu:** Dự án Tin học cuối học kỳ 2
- **Lớp:** 12A2
- **Nhóm:** Nhóm 3
- **Ngày hoàn thành:** 17/04/2025
- **Tác giả:** Huy Vu

## 🚀 Tính năng chính
- **Giao diện chuẩn Netflix:** Sử dụng Tailwind CSS để tạo ra giao diện sang trọng, dark mode và responsive.
- **Trình phát Video:** Tích hợp trình phát video cơ bản để xem phim trực tuyến.
- **Đăng nhập đơn giản:** Quy trình đăng nhập đã được tối giản hóa, chỉ cần một cú click là có thể trải nghiệm dịch vụ.
- **Responsive Design:** Giao diện hiển thị tốt trên cả máy tính và thiết bị di động.

## 🛠 Công nghệ sử dụng
- **HTML5:** Cấu trúc nội dung web.
- **Tailwind CSS:** Framework CSS cho giao diện hiện đại và nhanh chóng.
- **Vanilla JavaScript:** Xử lý logic chuyển trang và tương tác người dùng.
- **FontAwesome:** Bộ icon phong phú cho các nút bấm và trang trí.
